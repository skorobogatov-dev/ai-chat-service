# 🎯 Как работает MCP интеграция - Простым языком

## Что у вас есть

### 1. Weather MCP Server (порт 3000)
**Это:** Отдельный сервер, который предоставляет инструменты для погоды

**Что делает:**
- Принимает запросы по WebSocket (ws://localhost:3000/mcp)
- Предоставляет инструменты: `get_weather`, `get_forecast`
- Обращается к Open-Meteo API для получения реальных данных
- Возвращает данные о погоде

**Запускается:**
```bash
./run-weather-server.sh
# или
./gradlew runWeatherMCP
```

### 2. Основное приложение (порт 8080)
**Это:** REST API сервер, который общается с Claude AI

**Что делает:**
- Принимает HTTP запросы от пользователей
- Подключается к Weather MCP Server как MCP клиент
- Отправляет вопросы в Claude API
- Вызывает MCP инструменты когда Claude просит
- Возвращает ответы пользователям

**Запускается:**
```bash
export MCP_SERVER_URL="ws://localhost:3000/mcp"
export ANTHROPIC_API_KEY="your-key"
./run-main-with-mcp.sh
# или
./gradlew run
```

## Ключевые моменты

### ✅ Что ДЕЛАЕТ основное приложение

1. **Подключается к Weather MCP Server** (при старте)
2. **Получает список инструментов** (`get_weather`, `get_forecast`)
3. **Передает инструменты в Claude API** (вместе с вопросом)
4. **Получает от Claude указание** использовать инструмент
5. **ВЫЗЫВАЕТ Weather MCP Server** для получения данных
6. **Отправляет данные обратно Claude**
7. **Получает финальный ответ** и отправляет пользователю

### ✅ Что ДЕЛАЕТ Claude AI

1. **Получает вопрос** + список доступных инструментов
2. **Анализирует вопрос**: "Это о погоде в Москве"
3. **Принимает решение**: "Нужен get_weather для Moscow"
4. **Возвращает команду** использовать инструмент
5. **Получает результат** от инструмента
6. **Формирует красивый ответ** на естественном языке

### ✅ Что ДЕЛАЕТ Weather MCP Server

1. **Слушает WebSocket** на ws://localhost:3000/mcp
2. **Предоставляет инструменты** через MCP протокол
3. **Получает вызов инструмента** от основного приложения
4. **Обращается к Open-Meteo API** для реальных данных
5. **Форматирует и возвращает** данные о погоде

## Почему это круто?

### 🎯 Claude принимает решения

❌ **Без MCP:**
```kotlin
// Приложение парсит вопрос само
if (message.contains("погода")) {
    // Как извлечь город?
    // "А какая погодка нынче в матушке Москве?" - ???
    val city = ???
    val weather = getWeather(city)
}
```

✅ **С MCP:**
```kotlin
// Claude сам понимает контекст!
Claude: "Вопрос о погоде в Москве → get_weather(Moscow)"
Claude: "Какая погодка в матушке Москве → get_weather(Moscow)"
Claude: "Сколько градусов в столице РФ? → get_weather(Moscow)"
```

### 🔌 Модульность

- Weather MCP Server - отдельный процесс
- Можно добавить другие MCP серверы (база данных, файлы, калькулятор)
- Claude автоматически использует все доступные инструменты

### 🌐 Стандартный протокол

- MCP - это открытый стандарт от Anthropic
- Любой MCP сервер совместим
- Растущая экосистема готовых серверов
