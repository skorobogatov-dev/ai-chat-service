## Биллинговый цикл

### Ежемесячная подписка

- Оплата каждый месяц
- Автоматическое продление
- Можно отменить в любой момент
- Возврат пропорциональный неиспользованному времени

### Годовая подписка

- Оплата раз в год
- **Скидка 17%** по сравнению с ежемесячной
- Автоматическое продление через год
- Можно отменить в любой момент
- Возврат пропорциональный неиспользованному времени (первые 30 дней — полный возврат)

**Пример экономии (Premium):**
- Ежемесячно: $9.99 × 12 = $119.88/год
- Годовая подписка: $99.99/год
- **Экономия:** $19.89/год на пользователя

## Добавление и удаление пользователей

### Добавление пользователей

1. Настройки → Команда → "Добавить участника"
2. Введите email пользователя
3. Выберите роль
4. Отправьте приглашение

**Биллинг:**
- **Ежемесячная подписка**: Пропорциональная оплата за оставшийся месяц
- **Годовая подписка**: Немедленная оплата за полный год

**Пример:**
- Ваш биллинговый цикл: 1-е число каждого месяца
- Добавили пользователя 15-го числа
- Списание: $9.99 × 15/30 = $5.00 за этот месяц
- Со следующего месяца: полная стоимость $9.99

### Удаление пользователей

1. Настройки → Команда → Найти пользователя
2. Меню "..." → "Удалить из команды"
3. Подтвердите удаление

**Возврат средств:**
- **Ежемесячная подписка**: Пропорциональный кредит на следующий месяц
- **Годовая подписка**: Кредит на следующий период

## Изменение тарифа

### Повышение тарифа (Upgrade)

1. Настройки → Тарифный план → "Изменить тариф"
2. Выберите новый тариф (Premium или Enterprise)
3. Подтвердите

**Биллинг:**
- Немедленный доступ к новым функциям
- Пропорциональная оплата за текущий период
- Новая стоимость с следующего периода

**Пример:**
- Текущий тариф: Basic (бесплатно)
- Переход на Premium: $9.99/месяц
- Дата обновления: 15-е число месяца
- Списание: $9.99 × 15/30 = $5.00 за текущий месяц

### Понижение тарифа (Downgrade)

1. Настройки → Тарифный план → "Изменить тариф"
2. Выберите более низкий тариф
3. Подтвердите

**Биллинг:**
- Изменения вступают в силу в конце текущего периода
- Никаких немедленных списаний
- Кредит за неиспользованное время

**Важно:**
- При понижении до Basic сохраняются только первые 50 задач на проект
- Данные не удаляются, но становятся недоступны для редактирования
- Расширенные функции становятся недоступны

## Отмена подписки

### Как отменить

1. Настройки → Тарифный план → "Отменить подписку"
2. Выберите причину отмены (опционально)
3. Подтвердите

**Что происходит:**
- Подписка остается активной до конца оплаченного периода
- После окончания периода аккаунт переходит на тариф Basic (бесплатно)
- Никаких дополнительных списаний

### Возврат средств

**30-дневная гарантия возврата:**
- В течение 30 дней с момента оплаты — 100% возврат
- Без вопросов и объяснений
- Напишите на billing@taskmaster.pro

**После 30 дней:**
- Пропорциональный возврат за неиспользованное время
- Только для годовой подписки
- Обработка 5-7 рабочих дней

## Управление биллингом

### Обновление способа оплаты

1. Настройки → Биллинг → "Способ оплаты"
2. Нажмите "Обновить карту"
3. Введите новые данные карты
4. Сохраните

### Просмотр истории платежей

1. Настройки → Биллинг → "История платежей"
2. Просмотрите все транзакции
3. Скачайте счета (PDF)

### Изменение email для счетов

1. Настройки → Биллинг → "Email для счетов"
2. Введите новый email
3. Подтвердите изменение

### Получение счетов с НДС

Для организаций (ЕС, РФ):

1. Настройки → Биллинг → "Реквизиты компании"
2. Введите:
   - Название компании
   - ИНН/VAT ID
   - Юридический адрес
3. Сохраните
4. Счета будут включать НДС

## Частые вопросы

### Можно ли оплатить за несколько лет вперед?

Да, для Enterprise тарифа. Свяжитесь с sales@taskmaster.pro для специального предложения.

### Что происходит, если не оплатить вовремя?

1. За 7 дней до истечения — напоминание
2. В день истечения — повторное напоминание
3. Дни 1-7: Аккаунт в режиме чтения (нельзя редактировать)
4. Дни 8-30: Аккаунт заблокирован, данные сохраняются
5. После 30 дней: Аккаунт удаляется

### Можно ли перейти с ежемесячной на годовую подписку?

Да:
1. Настройки → Тарифный план → "Перейти на годовую подписку"
2. Получите скидку 17%
3. Кредит за оставшееся время ежемесячной подписки применится автоматически

### Есть ли скидки для некоммерческих организаций?

Да! Некоммерческие организации получают **50% скидку** на Premium и Enterprise.

Напишите на nonprofit@taskmaster.pro с подтверждением статуса.

### Есть ли скидки для студентов и образовательных учреждений?

Да!
- **Студенты**: Бесплатный Premium на 2 года
- **Учебные заведения**: 50% скидка на Enterprise

Подробнее: taskmaster.pro/education

### Можно ли оплатить за других пользователей?

Да, владелец аккаунта оплачивает за всех пользователей в команде.

### Как получить возврат?

Напишите на billing@taskmaster.pro с указанием:
- Email аккаунта
- Причина возврата (опционально)
- Номер транзакции (если есть)

Обработка: 5-7 рабочих дней.

### Можно ли попробовать Premium бесплатно?

Да! 14-дневная бесплатная пробная версия Premium:
1. Настройки → Тарифный план → "Попробовать Premium"
2. Карта не требуется
3. После окончания пробного периода автоматически перейдете на Basic
