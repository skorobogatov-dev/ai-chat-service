# Настройка уведомлений

## Типы уведомлений

TaskMaster Pro поддерживает три канала уведомлений:
- **Email** - уведомления на почту
- **Push** - мобильные уведомления (iOS/Android)
- **In-App** - уведомления в веб-приложении
- **Slack** - интеграция с каналами Slack (Premium+)

## Основные настройки

### Доступ к настройкам
1. Нажмите на ваш аватар в правом верхнем углу
2. Выберите "Настройки"
3. Перейдите на вкладку "Уведомления"

### Глобальное включение/выключение
В верхней части страницы:
- ☑ **Email уведомления** - получать письма
- ☑ **Push уведомления** - мобильные уведомления
- ☑ **Desktop уведомления** - уведомления в браузере

## Email уведомления

### События для уведомлений

**Задачи:**
- ☑ Вам назначили задачу
- ☑ Изменился статус задачи
- ☑ Изменился дедлайн задачи
- ☑ Приближается дедлайн (за 1 день)
- ☑ Дедлайн истек
- ☑ Вас упомянули в комментарии
- ☑ Добавлен новый комментарий к вашей задаче
- ☑ Задача завершена

**Проекты:**
- ☑ Вас добавили в проект
- ☑ Изменились настройки проекта
- ☑ Новые участники в проекте

**Командные:**
- ☐ Ежедневная сводка задач (8:00 AM)
- ☐ Еженедельный отчет (понедельник, 9:00 AM)

### Настройка частоты

**Режим доставки:**
- **Мгновенно** - уведомления отправляются сразу
- **Батч (каждый час)** - группировка уведомлений раз в час
- **Ежедневная сводка** - одно письмо в день с summary

### Тихие часы
Настройте время, когда уведомления не приходят:
1. Включите "Тихие часы"
2. Установите период: например, 22:00 - 8:00
3. Исключение: срочные уведомления всегда доставляются

### Unsubscribe (отписка)
В каждом письме есть ссылка "Отписаться". Вы можете:
- Отписаться от конкретного типа уведомлений
- Отписаться от всех email уведомлений
- Изменить настройки (перейти в Настройки)

## Push уведомления (мобильные)

### Включение Push на iOS
1. Откройте приложение TaskMaster Pro на iPhone/iPad
2. Перейдите в Настройки → Уведомления
3. Нажмите "Разрешить уведомления"
4. В системных настройках iOS разрешите уведомления для TaskMaster Pro

### Включение Push на Android
1. Откройте приложение на Android
2. Настройки → Уведомления
3. Включите "Push уведомления"
4. Выберите, какие события триггерят уведомления

### Настройка звуков и вибрации
- **Звук**: выберите мелодию для уведомлений
- **Вибрация**: включить/выключить
- **Значок на иконке**: показывать количество непрочитанных уведомлений

## Интеграция со Slack

**Доступно в:** Premium, Enterprise

### Подключение Slack
1. Настройки → Интеграции → Slack
2. Нажмите "Подключить Slack Workspace"
3. Авторизуйте TaskMaster Pro в вашем Slack
4. Выберите каналы для уведомлений

### Настройка уведомлений в Slack

**Уровень проекта:**
1. Откройте настройки проекта
2. Перейдите в "Интеграции" → "Slack"
3. Выберите канал: например, `#project-tasks`
4. Настройте события:
   - ☑ Новая задача создана
   - ☑ Задача завершена
   - ☑ Приближается дедлайн
   - ☑ Новый комментарий

**Личные уведомления:**
1. Настройки → Уведомления → Slack
2. Включите "Личные уведомления в Slack Direct Messages"
3. Выберите события для личных уведомлений

### Slack команды

В Slack можно использовать команды TaskMaster:
```
/task create [название] - создать задачу
/task list - показать мои задачи
/task complete [ID] - завершить задачу
```

## Автоматические напоминания

### Напоминания о дедлайнах

**По умолчанию:**
- За 1 день до дедлайна (9:00 AM)
- В день дедлайна (9:00 AM)
- При просрочке дедлайна (ежедневно до завершения)

**Настройка:**
1. Настройки → Уведомления → "Напоминания о дедлайнах"
2. Выберите время:
   - За 3 дня
   - За 1 день
   - В день дедлайна
   - За 2 часа (Premium)
   - Кастомное время (Premium)
3. Выберите время суток для напоминаний

### Напоминания о неназначенных задачах (Premium)
Автоматическое напоминание, если задача создана, но не назначена:
- Через 24 часа после создания
- Раз в 3 дня, пока не назначат

### Напоминания о долгих задачах (Premium)
Если задача "В работе" более N дней:
- Напоминание исполнителю
- Уведомление создателя задачи
- Предложение обновить статус

## Управление уведомлениями по проектам

### Подписка на проект
- **Все уведомления** - получать все обновления проекта
- **Только мои задачи** - только по задачам, где вы исполнитель
- **Важные события** - только критичные изменения
- **Отключить** - не получать уведомления из этого проекта

### Изменение подписки
1. Откройте проект
2. Нажмите 🔔 (колокольчик) в правом верхнем углу
3. Выберите уровень подписки

## Частые проблемы

### "Не приходят email уведомления"

**Решение:**
1. Проверьте папку "Спам" в почте
2. Добавьте `notifications@taskmaster.pro` в адресную книгу
3. Проверьте настройки: Настройки → Уведомления → Email
4. Убедитесь, что email адрес подтвержден (Профиль → Email → "Подтвердить")
5. Проверьте, нет ли "Тихих часов"

### "Слишком много уведомлений"

**Решение:**
1. Переключите режим доставки с "Мгновенно" на "Батч (каждый час)"
2. Отключите уведомления для менее важных событий
3. Отпишитесь от некритичных проектов
4. Используйте фильтры email для автоматической сортировки

### "Push уведомления не работают на iPhone"

**Решение:**
1. Настройки iOS → Уведомления → TaskMaster Pro
2. Убедитесь, что уведомления разрешены
3. Проверьте, что "Режим фокусирования" не блокирует уведомления
4. Переустановите приложение (сохраните данные!)
5. Проверьте в приложении: Настройки → Уведомления → "Разрешить уведомления"

### "Уведомления в Slack дублируются"

**Причина:** Настроены как личные, так и канальные уведомления

**Решение:**
1. Настройки → Интеграции → Slack
2. Отключите либо личные, либо канальные уведомления
3. Или настройте разные события для каждого типа

### "Не получаю уведомления об упоминаниях"

**Решение:**
1. Проверьте Настройки → Уведомления → "Вас упомянули в комментарии"
2. Убедитесь, что используется правильный формат: `@username`
3. Проверьте, что уведомления не отключены для этого проекта

## Расширенные настройки (Premium)

### Кастомные правила уведомлений
Создайте правила для автоматизации уведомлений:

**Пример:**
"Если задача с приоритетом 'Срочный' не завершена за 2 дня → уведомить руководителя"

1. Настройки → Уведомления → "Кастомные правила"
2. Нажмите "Создать правило"
3. Настройте условия:
   - Когда: приоритет = Срочный
   - И: дней с создания > 2
   - И: статус ≠ Завершена
4. Действие: отправить уведомление → выберите получателя
5. Сохраните правило

### Интеграция с календарем
Добавляйте события TaskMaster в Google Calendar:
1. Настройки → Интеграции → Google Calendar
2. Включите синхронизацию
3. Выберите, что синхронизировать:
   - ☑ Задачи с дедлайнами
   - ☑ Напоминания
   - ☑ Встречи команды

## Отключение всех уведомлений

Если нужна тишина (отпуск, фокус-время):
1. Настройки → Уведомления
2. Нажмите "Режим не беспокоить"
3. Выберите длительность: 1 час, 8 часов, 1 день, 1 неделя
4. Или установите кастомный период

**Во время "Не беспокоить":**
- Все уведомления отключены
- Вы все равно можете проверять приложение
- Срочные упоминания от руководства будут доставлены (опционально)
