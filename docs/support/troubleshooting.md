# Устранение неполадок

## Распространенные ошибки

### Ошибка 403: "Недостаточно прав"

**Что означает:**
Вы пытаетесь выполнить действие, для которого у вас нет прав.

**Возможные причины:**
1. Вы не являетесь участником проекта
2. У вас роль "Наблюдатель" (только чтение)
3. Проект находится в архиве
4. Ваш аккаунт заблокирован администратором

**Решение:**
1. Проверьте вашу роль в проекте: Проект → Участники → найдите себя
2. Попросите администратора проекта повысить ваши права
3. Если проект в архиве — попросите владельца восстановить его
4. Свяжитесь с администратором организации если аккаунт заблокирован

### Ошибка 500: "Внутренняя ошибка сервера"

**Что означает:**
Произошла ошибка на стороне сервера TaskMaster Pro.

**Решение:**
1. Обновите страницу браузера (F5 или Cmd+R)
2. Очистите кэш браузера
3. Попробуйте через 5-10 минут
4. Проверьте статус системы: status.taskmaster.pro
5. Если проблема сохраняется более 30 минут — сообщите в поддержку с описанием действия, которое вызвало ошибку

### Ошибка 401: "Unauthorized"

**Что означает:**
Ваша сессия истекла или токен недействителен.

**Решение:**
1. Обновите страницу — будет предложено войти заново
2. Если проблема повторяется — выйдите из аккаунта и войдите снова
3. Очистите cookies для домена taskmaster.pro
4. Проверьте, не истек ли ваш API ключ (если используете API)

## Проблемы с загрузкой и производительностью

### Медленная загрузка приложения

**Причины:**
- Медленное интернет-соединение
- Большое количество задач в проекте
- Проблемы с кэшем браузера
- Проблемы на стороне сервера

**Решение:**
1. Проверьте скорость интернета: fast.com
2. Очистите кэш браузера:
   - Chrome: Настройки → Конфиденциальность → Очистить данные
   - Firefox: Настройки → Приватность → Очистить историю
   - Safari: История → Очистить историю
3. Отключите расширения браузера временно
4. Попробуйте другой браузер
5. Проверьте status.taskmaster.pro на наличие инцидентов

### Список задач загружается более 10 секунд

**Если у вас более 500 задач в проекте:**

**Решение:**
1. Используйте фильтры для уменьшения количества отображаемых задач
2. Архивируйте завершенные задачи:
   - Настройки проекта → Автоархивация
   - Включите "Архивировать завершенные задачи через 30 дней"
3. Используйте пагинацию: Настройки → Отображение → Задач на странице: 50
4. Разделите большой проект на несколько меньших

## Проблемы с сохранением данных

### "Задачи не сохраняются"

**Причины:**
- Потеря интернет-соединения
- Проблема с синхронизацией
- Конфликт версий (два пользователя редактируют одновременно)

**Решение:**
1. Проверьте индикатор соединения в правом верхнем углу
2. Если офлайн — подождите восстановления интернета, данные сохранятся автоматически
3. При конфликте версий:
   - Появится предупреждение "Конфликт изменений"
   - Выберите: "Сохранить мою версию" или "Использовать версию сервера"
4. Включите автосохранение: Настройки → Редактор → Автосохранение каждые 5 секунд

### "Изменения откатываются после обновления страницы"

**Причина:** Изменения не были сохранены на сервер

**Решение:**
1. Всегда ждите появления галочки "Сохранено" после внесения изменений
2. Не закрывайте вкладку сразу после редактирования
3. Используйте сочетание Ctrl+S (Cmd+S на Mac) для принудительного сохранения

## Проблемы с фильтрами и поиском

### "Фильтр не работает / не обновляется"

**Решение:**
1. Очистите все фильтры и примените заново
2. Обновите страницу (F5)
3. Проверьте синтаксис фильтров (для расширенных фильтров)
4. Очистите кэш браузера
5. Попробуйте другой браузер

### "Поиск не находит задачи, хотя они существуют"

**Причины:**
- Индекс поиска не обновился
- Задача находится в архиве
- Недостаточно прав для просмотра

**Решение:**
1. Проверьте фильтр "Статус" — включите "Архивные"
2. Попробуйте поиск через несколько минут (индекс обновляется каждые 5 минут)
3. Используйте расширенный поиск с операторами: `status:any created:>2024-01-01`
4. Проверьте права доступа к проекту

## Проблемы с уведомлениями

### "Не приходят уведомления на email"

**Полное руководство:** См. `notifications-settings.md`

**Быстрые проверки:**
1. Папка "Спам" в почте
2. Настройки → Уведомления → Email → убедитесь, что включено
3. Профиль → Email → проверьте, что email подтвержден
4. Добавьте `notifications@taskmaster.pro` в адресную книгу

### "Слишком много уведомлений"

**Решение:**
1. Настройки → Уведомления
2. Переключите с "Мгновенно" на "Ежедневная сводка"
3. Отключите уведомления для менее важных событий
4. Отпишитесь от определенных проектов

## Проблемы с интеграциями

### Google Calendar

**Проблема:** "Задачи не синхронизируются с Google Calendar"

**Решение:**
1. Настройки → Интеграции → Google Calendar
2. Нажмите "Синхронизировать сейчас"
3. Если не помогло — отключите и подключите Google Calendar заново
4. Проверьте права доступа: myaccount.google.com → Security → Apps with access
5. Убедитесь, что задачи имеют дедлайн (без дедлайна не синхронизируются)

### Slack

**Проблема:** "Уведомления не приходят в Slack"

**Решение:**
1. Проверьте, что TaskMaster Pro установлен в вашем Slack workspace
2. Настройки → Интеграции → Slack → переподключите
3. Проверьте права бота в канале: `/invite @TaskMaster`
4. Убедитесь, что уведомления настроены для нужного канала

## Проблемы с мобильным приложением

### iOS приложение

**"Приложение крашится при запуске"**

**Решение:**
1. Обновите приложение до последней версии (App Store)
2. Перезагрузите iPhone/iPad
3. Удалите и переустановите приложение (данные сохраняются на сервере)
4. Проверьте, достаточно ли свободного места на устройстве

**"Синхронизация не работает"**

**Решение:**
1. Проверьте интернет-соединение (WiFi или мобильные данные)
2. Настройки приложения → Аккаунт → "Принудительная синхронизация"
3. Выйдите из аккаунта и войдите заново

### Android приложение

**"Приложение тормозит / зависает"**

**Решение:**
1. Обновите приложение (Google Play)
2. Очистите кэш: Настройки Android → Приложения → TaskMaster → Очистить кэш
3. Перезагрузите устройство
4. Если проблема в старом устройстве — используйте веб-версию

## Проблемы с вложениями

### "Не могу загрузить файл"

**Причины:**
- Файл слишком большой (лимит 25 МБ)
- Неподдерживаемый формат
- Превышен лимит хранилища

**Решение:**
1. Проверьте размер файла (максимум 25 МБ на файл)
2. Поддерживаемые форматы: изображения, документы, PDF, архивы
3. Проверьте доступное хранилище: Настройки → Использование → Хранилище
4. Если лимит превышен — удалите старые вложения или обновите тариф
5. Попробуйте загрузить файл через другой браузер

### "Не открывается вложение"

**Решение:**
1. Попробуйте скачать файл на компьютер
2. Проверьте формат файла — возможно, нужна специальная программа
3. Если файл не скачивается — возможно, он был удален владельцем
4. Попробуйте открыть в другом браузере

## Проблемы с экспортом/импортом

### "Ошибка при импорте CSV"

**Частые ошибки:**
- Invalid date format
- Missing required field: Title
- Invalid status value

**Решение:**
1. Проверьте формат дат: используйте YYYY-MM-DD
2. Убедитесь, что есть колонка "Title" или "Название"
3. Проверьте статусы: должны быть "Открыта", "В работе", "Завершена" (или на английском)
4. Используйте UTF-8 кодировку для файла
5. Скачайте образец CSV: Импорт → "Скачать пример файла"

### "Не экспортируются подзадачи"

**Причина:** Доступно только в Premium/Enterprise

**Решение:**
- Обновите тариф до Premium
- Или используйте JSON формат для экспорта полных данных (также Premium)

## Проблемы с биллингом

### "Оплата не прошла"

**Решение:**
1. Проверьте данные карты: срок действия, CVV
2. Убедитесь, что на карте достаточно средств
3. Проверьте лимиты на онлайн-платежи
4. Попробуйте другую карту
5. Свяжитесь с поддержкой: billing@taskmaster.pro

### "После оплаты функции Premium не активировались"

**Решение:**
1. Обновите страницу браузера
2. Выйдите и войдите в аккаунт
3. Подождите до 10 минут (обработка платежа)
4. Проверьте email — должно прийти подтверждение оплаты
5. Если более 30 минут — свяжитесь с поддержкой

## Общие рекомендации

### Очистка кэша браузера

**Chrome:**
1. Настройки → Конфиденциальность и безопасность
2. Очистить данные браузера
3. Выберите "За все время"
4. Отметьте: Кэш, Cookies, Изображения
5. Очистить данные

**Firefox:**
1. Настройки → Приватность и защита
2. Cookies и данные сайтов → Удалить данные
3. Отметьте нужные пункты
4. Удалить

**Safari:**
1. Safari → Настройки → Дополнения
2. Включите "Меню разработки"
3. Разработка → Очистить кэши
