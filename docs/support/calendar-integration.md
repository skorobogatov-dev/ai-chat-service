# Интеграция с календарем

## Google Calendar синхронизация

### Подключение Google Calendar

**Доступно в:** Premium, Enterprise

1. Перейдите в Настройки → Интеграции → Google Calendar
2. Нажмите "Подключить Google Calendar"
3. Выберите ваш Google аккаунт
4. Разрешите TaskMaster Pro доступ к вашему календарю
5. Выберите календарь для синхронизации (или создайте новый)

### Двусторонняя синхронизация

**Как это работает:**
- Задачи с дедлайнами → события в Google Calendar
- События из Google Calendar → задачи в TaskMaster (опционально)
- Изменения синхронизируются автоматически каждые 15 минут

**Настройка синхронизации:**
1. Настройки → Интеграции → Google Calendar
2. Включите опции:
   - ☑ **Синхронизировать задачи → Calendar**: экспорт задач с дедлайнами
   - ☐ **Синхронизировать Calendar → задачи**: импорт событий как задач
   - ☑ **Напоминания**: синхронизировать напоминания
   - ☑ **Обновления**: синхронизировать изменения в обе стороны
3. Сохраните настройки

### Что синхронизируется

**Из TaskMaster в Google Calendar:**
- Название задачи → Название события
- Дедлайн → Дата и время события
- Описание задачи → Описание события
- Приоритет → Цвет события (Срочный = красный, Высокий = оранжевый)
- Исполнители → Участники события

**Из Google Calendar в TaskMaster (опционально):**
- Название события → Название задачи
- Дата события → Дедлайн задачи
- Описание → Описание задачи
- Участники → Исполнители (если они есть в проекте)

### Фильтрация задач для синхронизации

Вы можете выбрать, какие задачи синхронизировать:

1. Настройки → Интеграции → Google Calendar → "Фильтры"
2. Выберите критерии:
   - ☑ Только задачи с дедлайном
   - ☑ Только задачи с высоким приоритетом
   - ☐ Все задачи
   - ☑ Только мои задачи
   - ☐ Задачи всей команды
3. Выберите проекты для синхронизации

## Настройка отображения в календаре

### Формат событий

**Шаблон названия:**
По умолчанию: `[TaskMaster] Название задачи`

Настройте кастомный формат:
1. Настройки → Интеграции → Google Calendar → "Формат событий"
2. Используйте переменные:
   - `{task}` - название задачи
   - `{project}` - название проекта
   - `{priority}` - приоритет
   - `{assignee}` - исполнитель

Пример: `{project} | {task} ({priority})`
Результат: `Website Redesign | Fix homepage bug (High)`

### Длительность событий

По умолчанию задачи отображаются как события на весь день.

Настройка времени:
1. При создании задачи укажите время дедлайна: `2024-12-15 14:00`
2. Укажите расчетное время выполнения (в настройках задачи)
3. Событие будет создано с конкретным временем и длительностью

### Цветовая кодировка

События окрашиваются по приоритету:
- **Серый** - Низкий приоритет
- **Зеленый** - Средний приоритет
- **Оранжевый** - Высокий приоритет
- **Красный** - Срочный приоритет

## Частые проблемы

### "Задачи не появляются в календаре"

**Решение:**
1. Проверьте, что синхронизация включена
2. Убедитесь, что задача имеет дедлайн (без дедлайна не синхронизируется)
3. Проверьте фильтры: возможно, задача не попадает под критерии
4. Принудительная синхронизация: Настройки → Google Calendar → "Синхронизировать сейчас"
5. Подождите до 15 минут (автоматическая синхронизация)
6. Проверьте, выбран ли правильный календарь в Google Calendar (не скрыт)

### "Дублирование событий"

**Причина:** Несколько календарей синхронизируются одновременно

**Решение:**
1. Настройки → Google Calendar → "Управление календарями"
2. Убедитесь, что выбран только один календарь для синхронизации
3. Удалите дублирующие события вручную
4. Нажмите "Пересинхронизировать" для очистки и повторной загрузки

### "События исчезают из календаря"

**Возможные причины:**
1. Задача была удалена → событие тоже удаляется
2. Задача была завершена → событие удаляется (по умолчанию)
3. Дедлайн был снят с задачи → событие удаляется

**Настройка поведения:**
1. Настройки → Google Calendar → "Завершенные задачи"
2. Выберите действие:
   - Удалить событие
   - Оставить событие (зачеркнуть название)
   - Переместить в архивный календарь

### "Изменения не синхронизируются"

**Решение:**
1. Проверьте подключение к интернету
2. Убедитесь, что токен Google не истек (переподключите аккаунт)
3. Проверьте права доступа: Google Account → Security → Apps with access
4. Принудительная синхронизация: Настройки → "Синхронизировать сейчас"
5. Перезапустите синхронизацию: отключите и подключите Google Calendar заново

## Apple Calendar (iCal) интеграция

**Доступно в:** Premium, Enterprise

### Подписка через iCal ссылку

1. TaskMaster Pro → Настройки → Интеграции → "iCal Feed"
2. Скопируйте iCal URL (например: `webcal://api.taskmaster.pro/ical/abc123`)
3. Откройте Apple Calendar (или любое приложение, поддерживающее iCal)
4. Файл → Новая подписка на календарь
5. Вставьте URL и нажмите "Подписаться"
6. Выберите частоту обновления: каждые 15 минут, каждый час, каждый день

**Ограничения:**
- Только чтение (изменения из Apple Calendar не синхронизируются обратно)
- Автоматическое обновление зависит от настроек вашего приложения

## Outlook Calendar интеграция

**Доступно в:** Enterprise

### Подключение через Microsoft 365

1. Настройки → Интеграции → Outlook Calendar
2. Нажмите "Подключить Outlook"
3. Войдите в ваш Microsoft аккаунт
4. Разрешите доступ к календарю
5. Выберите календарь для синхронизации

**Функции:**
- Двусторонняя синхронизация (как Google Calendar)
- Поддержка нескольких календарей
- Синхронизация участников встреч

## Расширенные настройки

### Автоматическое создание событий для встреч

**Premium+:**
1. Настройки → Интеграции → Calendar → "Встречи команды"
2. Включите "Автоматически создавать события для встреч"
3. При создании задачи типа "Встреча":
   - Указывается дата и время
   - Приглашаются участники (исполнители)
   - Автоматически отправляются приглашения на email

### Блокировка времени (Time Blocking)

**Premium+:**
1. Включите "Time Blocking" в настройках
2. При назначении задачи себе:
   - Выбирается автоматически свободное время в календаре
   - Создается событие "Фокус-время: [Задача]"
   - Блокируется время для выполнения задачи

### Синхронизация с несколькими календарями

**Enterprise:**
1. Настройки → Интеграции → Календари
2. Подключите несколько календарей:
   - Рабочий Google Calendar
   - Личный Google Calendar
   - Outlook Calendar
3. Настройте правила распределения:
   - Рабочие задачи → Рабочий календарь
   - Личные задачи → Личный календарь

## Мобильные приложения

### iOS Calendar интеграция

События из TaskMaster автоматически доступны в iOS Calendar, если настроена синхронизация с Google/iCloud.

**Проверка:**
1. Настройки iOS → Календарь → Учетные записи
2. Убедитесь, что Google аккаунт добавлен
3. Включите синхронизацию календаря

### Android Calendar интеграция

События автоматически синхронизируются с Google Calendar и отображаются в Android Calendar.

**Настройка:**
1. Настройки Android → Аккаунты → Google
2. Убедитесь, что "Календарь" включен
3. Откройте Google Calendar app
4. Убедитесь, что календарь TaskMaster видим

## Отключение синхронизации

### Временное отключение
1. Настройки → Интеграции → Google Calendar
2. Переключите "Синхронизация" в OFF
3. События останутся в календаре, но новые обновления не будут синхронизироваться

### Полное отключение и удаление событий
1. Настройки → Интеграции → Google Calendar
2. Нажмите "Отключить и удалить события"
3. Все события TaskMaster будут удалены из вашего календаря
4. Подключение будет разорвано
