# Руководство по экспорту и импорту данных

## Экспорт задач

### Форматы экспорта

TaskMaster Pro поддерживает экспорт в следующие форматы:
- **CSV**: Таблица с основными полями (Excel, Google Sheets)
- **Excel (XLSX)**: Расширенный формат с форматированием
- **JSON**: Полный экспорт всех данных для разработчиков
- **PDF**: Печатная версия списка задач (Premium)

### Базовый экспорт (CSV)

**Доступно в:** Basic, Premium, Enterprise

1. Откройте проект или список задач
2. Нажмите кнопку "..." (меню) в правом верхнем углу
3. Выберите "Экспорт" → "CSV"
4. Выберите поля для экспорта:
   - Название задачи
   - Статус
   - Приоритет
   - Исполнитель
   - Дедлайн
   - Дата создания
5. Нажмите "Скачать"
6. Файл будет сохранен в формате `project-name-YYYY-MM-DD.csv`

**Ограничения Basic тарифа:**
- Экспортируются только основные поля
- Подзадачи не включаются
- Комментарии не включаются
- Вложения не экспортируются

### Расширенный экспорт (Excel/JSON)

**Доступно в:** Premium, Enterprise

#### Excel экспорт
1. Проект → меню "..." → "Экспорт" → "Excel"
2. Выберите дополнительные опции:
   - ☑ Включить подзадачи
   - ☑ Включить комментарии
   - ☑ Включить историю изменений
   - ☑ Включить вложения (ссылки)
3. Выберите диапазон дат (опционально)
4. Нажмите "Экспортировать"

**Результат:**
- Основной лист: список всех задач
- Лист "Подзадачи": связанные подзадачи
- Лист "Комментарии": все комментарии с автором и датой
- Форматирование по приоритетам (цветовая кодировка)

#### JSON экспорт
1. Проект → меню "..." → "Экспорт" → "JSON"
2. Полный экспорт всех данных включая:
   - Задачи и подзадачи (иерархия)
   - Комментарии с авторами
   - История изменений
   - Метаданные проекта
   - Ссылки на вложения
3. Формат соответствует API спецификации

### Экспорт проекта целиком

**Доступно в:** Premium, Enterprise

1. Настройки проекта → "Экспорт и бэкап"
2. Нажмите "Экспортировать весь проект"
3. Включите опции:
   - ☑ Все задачи и подзадачи
   - ☑ Все комментарии
   - ☑ Вложения (скачает ZIP архив)
   - ☑ Настройки проекта (теги, статусы)
   - ☑ Участники и права доступа
4. Нажмите "Создать архив"
5. Процесс может занять несколько минут
6. Вы получите email со ссылкой на скачивание

**Размер архива:**
- Без вложений: обычно <1 МБ
- С вложениями: зависит от размера файлов

## Импорт задач

### Импорт из CSV

**Доступно в:** Basic, Premium, Enterprise

1. Откройте проект
2. Нажмите "Импорт" → "Из CSV"
3. Загрузите CSV файл
4. Сопоставьте колонки:
   - Название задачи → Title
   - Описание → Description
   - Исполнитель → Assigned To
   - Дедлайн → Due Date
   - Приоритет → Priority
   - Статус → Status
5. Просмотрите превью (первые 10 строк)
6. Нажмите "Импортировать"

**Требования к CSV файлу:**
- Первая строка — заголовки колонок
- Кодировка: UTF-8
- Разделитель: запятая или точка с запятой
- Обязательное поле: "Title" или "Название"

**Обработка дат:**
- Поддерживаемые форматы: YYYY-MM-DD, DD.MM.YYYY, MM/DD/YYYY
- Время опционально: YYYY-MM-DD HH:MM

### Импорт из других систем

**Доступно в:** Premium, Enterprise

#### Из Trello
1. Экспортируйте доску из Trello (JSON формат)
2. TaskMaster Pro → Импорт → "Из Trello"
3. Загрузите JSON файл
4. Выберите списки для импорта
5. Настройте сопоставление статусов:
   - To Do → Открыта
   - In Progress → В работе
   - Done → Завершена
6. Нажмите "Импортировать"

**Что импортируется:**
- Карточки → Задачи
- Чек-листы → Подзадачи
- Комментарии → Комментарии
- Метки → Теги
- Участники → Назначения

#### Из Asana
1. Экспортируйте проект из Asana (CSV)
2. TaskMaster Pro → Импорт → "Из Asana"
3. Загрузите CSV файл
4. Система автоматически распознает формат Asana
5. Нажмите "Импортировать"

#### Из Jira (Enterprise)
1. Используйте Jira REST API экспорт
2. TaskMaster Pro → Импорт → "Из Jira"
3. Введите URL вашего Jira и API токен
4. Выберите проекты для импорта
5. Настройте сопоставление полей
6. Запустите импорт

**Продвинутая миграция:**
- История изменений
- Связи между задачами
- Приоритеты и типы задач
- Пользовательские поля

### Импорт вложений

**Доступно в:** Premium, Enterprise

1. Подготовьте ZIP архив с файлами
2. Структура архива:
```
attachments.zip
├── task-001/
│   ├── document.pdf
│   └── image.png
├── task-002/
│   └── report.xlsx
└── mapping.csv (соответствие файлов и задач)
```
3. Импорт → "Импорт вложений"
4. Загрузите ZIP архив
5. Система автоматически прикрепит файлы к соответствующим задачам

## Автоматические бэкапы

**Доступно в:** Premium, Enterprise

### Настройка автобэкапов
1. Настройки проекта → "Бэкапы"
2. Включите "Автоматические бэкапы"
3. Выберите частоту:
   - Ежедневно (в 3:00 AM по UTC)
   - Еженедельно (воскресенье)
   - Ежемесячно (1-е число)
4. Выберите хранилище:
   - TaskMaster Cloud (30 дней хранения)
   - Google Drive (ваш аккаунт)
   - Dropbox (ваш аккаунт)
5. Сохраните настройки

### Восстановление из бэкапа
1. Настройки проекта → "Бэкапы"
2. Просмотрите список доступных бэкапов
3. Выберите нужный бэкап
4. Нажмите "Восстановить"
5. **Внимание:** Текущие данные будут заменены!
6. Рекомендуется создать снимок перед восстановлением

## API для импорта/экспорта

**Доступно в:** Enterprise

### REST API endpoints

```bash
# Экспорт задач
GET /api/v1/projects/{projectId}/export?format=json

# Импорт задач
POST /api/v1/projects/{projectId}/import
Content-Type: application/json
Body: { "tasks": [...] }

# Массовое обновление
PATCH /api/v1/projects/{projectId}/tasks/bulk
Body: { "updates": [...] }
```

Полная документация API: api.taskmaster.pro/docs

## Частые проблемы

### "Не экспортируются подзадачи"
**Решение:** Подзадачи доступны только в Premium/Enterprise. Обновите тариф или экспортируйте только основные задачи.

### "Ошибка при импорте CSV: Invalid date format"
**Решение:**
- Проверьте формат дат в CSV: используйте YYYY-MM-DD
- Убедитесь, что даты не содержат некорректных значений (31 февраля, 13-й месяц)
- Пустые даты допустимы

### "Импорт зависает на больших файлах"
**Решение:**
- Разбейте CSV на несколько файлов по 1000 задач
- Или используйте JSON формат (быстрее обрабатывается)
- Для очень больших проектов (>10 000 задач) свяжитесь с поддержкой для массового импорта

### "Потеряны комментарии после импорта"
**Причина:** Формат CSV не поддерживает комментарии
**Решение:** Используйте JSON формат для полного импорта всех данных

### "Вложения не импортировались"
**Решение:**
- Вложения импортируются только в Premium/Enterprise
- При импорте из CSV/Excel вложения нужно загружать отдельно через ZIP архив
- При импорте из Trello/Asana ссылки на вложения сохраняются, но файлы нужно скачать вручную
