# Часто задаваемые вопросы (FAQ)

## Общие вопросы

### Что такое TaskMaster Pro?

TaskMaster Pro — это современная платформа для управления задачами и проектами. Мы помогаем командам организовать работу, отслеживать прогресс и достигать целей эффективно.

### Сколько стоит TaskMaster Pro?

- **Basic**: Бесплатно (до 5 пользователей, 50 задач на проект)
- **Premium**: $9.99/месяц на пользователя
- **Enterprise**: Индивидуальная цена

Подробнее: docs.taskmaster.pro/pricing

### Есть ли мобильное приложение?

Да! TaskMaster Pro доступен на:
- **iOS**: App Store (iPhone, iPad)
- **Android**: Google Play
- **Web**: Любой современный браузер
- **Desktop**: Windows, macOS, Linux

### Можно ли использовать TaskMaster Pro бесплатно?

Да, тариф Basic полностью бесплатный и включает:
- До 5 пользователей
- 50 задач на проект
- Базовые интеграции
- 1 ГБ хранилища
- Email поддержка

## Аккаунт и безопасность

### Как создать аккаунт?

1. Перейдите на app.taskmaster.pro/signup
2. Зарегистрируйтесь через email или Google/GitHub OAuth
3. Подтвердите email (придет письмо)
4. Начните использовать TaskMaster Pro

### Безопасны ли мои данные?

Да! Мы обеспечиваем:
- Шифрование TLS 1.3 при передаче
- Шифрование AES-256 в хранилище
- Двухфакторная аутентификация (2FA)
- Регулярные бэкапы
- GDPR compliance
- SOC 2 Type II (Enterprise)

### Как включить двухфакторную аутентификацию (2FA)?

1. Профиль → Настройки → Безопасность
2. Включить 2FA
3. Отсканировать QR код в приложении-аутентификаторе
4. Ввести код подтверждения
5. Сохранить резервные коды

Подробнее: docs.taskmaster.pro/authentication-guide

### Как изменить тариф?

1. Настройки → Тарифный план
2. Нажмите "Изменить тариф"
3. Выберите нужный тариф
4. Введите данные для оплаты
5. Подтвердите изменение

Изменение вступает в силу немедленно.

### Можно ли перейти на более низкий тариф?

Да, вы можете понизить тариф в любой момент:
1. Настройки → Тарифный план → "Изменить тариф"
2. Выберите более низкий тариф
3. Подтвердите

**Внимание:** При переходе с Premium на Basic:
- Сохраняются только первые 50 задач на проект
- Доступ к расширенным функциям будет ограничен
- Данные не удаляются, но становятся недоступны для редактирования

### Как удалить аккаунт?

1. Профиль → Настройки → Безопасность
2. Прокрутите вниз → "Удалить аккаунт"
3. Введите пароль для подтверждения
4. Подтвердите удаление

**Важно:** Удаление необратимо. Все данные будут удалены через 30 дней. В течение этого периода можно восстановить аккаунт через поддержку.

## Задачи и проекты

### Сколько задач можно создать?

- **Basic**: 50 задач на проект
- **Premium**: Неограниченно
- **Enterprise**: Неограниченно

### Сколько пользователей можно добавить?

- **Basic**: До 5 пользователей
- **Premium**: До 50 пользователей
- **Enterprise**: Неограниченно

### Как создать подзадачу?

1. Откройте задачу
2. Найдите раздел "Подзадачи"
3. Нажмите "Добавить подзадачу"
4. Введите название и нажмите Enter

Подробнее: docs.taskmaster.pro/task-management-guide

### Как установить повторяющуюся задачу?

1. Создайте задачу
2. Включите "Повторяющаяся задача"
3. Выберите частоту: ежедневно, еженедельно, ежемесячно, ежегодно
4. Установите дату окончания (опционально)

### Можно ли экспортировать задачи?

Да!
- **Basic**: CSV экспорт (основные поля)
- **Premium/Enterprise**: CSV, Excel, JSON (полный экспорт включая подзадачи и комментарии)

Как: Проект → меню "..." → Экспорт

### Поддерживается ли импорт из Trello/Asana?

Да, в тарифах Premium и Enterprise:
- **Trello**: импорт через JSON
- **Asana**: импорт через CSV
- **Jira**: импорт через API (Enterprise)

Подробнее: docs.taskmaster.pro/export-import-guide

## Уведомления

### Как настроить email уведомления?

1. Настройки → Уведомления
2. Включите "Email уведомления"
3. Выберите события для уведомлений
4. Настройте частоту: мгновенно, каждый час, ежедневная сводка

Подробнее: docs.taskmaster.pro/notifications-settings

### Почему не приходят уведомления?

Проверьте:
1. Папка "Спам" в почте
2. Настройки → Уведомления → убедитесь, что включено
3. Email подтвержден (Профиль → Email)
4. Нет "Тихих часов"
5. Добавьте notifications@taskmaster.pro в адресную книгу

Если не помогло: docs.taskmaster.pro/troubleshooting

### Как отключить уведомления для конкретного проекта?

1. Откройте проект
2. Нажмите 🔔 (колокольчик) в правом верхнем углу
3. Выберите "Отключить уведомления"

## Технические вопросы

### Какие браузеры поддерживаются?

**Полностью поддерживаются:**
- Chrome 100+
- Firefox 100+
- Safari 15+
- Edge 100+

**Частично поддерживаются:**
- Старые версии браузеров (могут быть ограничения)

Рекомендуем использовать последние версии браузеров.

### Как экспортировать задачи в CSV?

1. Откройте проект
2. Меню "..." → Экспорт → CSV
3. Выберите поля для экспорта
4. Нажмите "Скачать"

### Почему приложение тормозит?

Возможные причины:
- Медленное интернет-соединение
- Много задач в проекте (>1000)
- Проблемы с кэшем браузера

**Решение:**
1. Очистите кэш браузера
2. Используйте фильтры для уменьшения количества задач
3. Архивируйте завершенные задачи
4. Попробуйте другой браузер

Подробнее: docs.taskmaster.pro/troubleshooting

### Доступен ли TaskMaster Pro через API?

Да, REST API доступен в тарифе Enterprise.

**Основные endpoints:**
- GET /api/v1/tasks - получить задачи
- POST /api/v1/tasks - создать задачу
- PUT /api/v1/tasks/:id - обновить задачу
- DELETE /api/v1/tasks/:id - удалить задачу

Документация: api.taskmaster.pro/docs

### Как получить API ключ?

**Enterprise тариф:**
1. Настройки → API & Интеграции
2. Нажмите "Создать API ключ"
3. Введите название (например, "Mobile App")
4. Выберите права доступа (scopes)
5. Скопируйте ключ (показывается один раз!)

## Биллинг и оплата

### Какие способы оплаты поддерживаются?

- **Банковские карты**: Visa, Mastercard, Maestro
- **PayPal**
- **Банковский перевод** (для Enterprise, от $1000/год)
- **Криптовалюта** (Bitcoin, Ethereum) - только Enterprise

### Можно ли оплатить годовой подпиской?

Да! При годовой оплате скидка:
- **Premium**: $99.99/год вместо $119.88 (скидка 17%)
- **Enterprise**: Индивидуальные условия

### Что происходит, если не оплатить вовремя?

1. За 7 дней до истечения — email напоминание
2. В день истечения — повторное напоминание
3. После истечения:
   - **Дни 1-7**: Аккаунт работает в режиме чтения (нельзя создавать/редактировать)
   - **Дни 8-30**: Аккаунт заблокирован, данные сохраняются
   - **После 30 дней**: Аккаунт удаляется, данные не восстановить

### Возвращаются ли деньги?

Да, у нас 30-дневная гарантия возврата:
- Если вы не удовлетворены — напишите на billing@taskmaster.pro
- Мы вернем 100% средств (в течение 30 дней с момента оплаты)
- Без вопросов и объяснений

### Можно ли получить счет на оплату?

Да (для организаций):
1. Настройки → Биллинг → "Запросить счет"
2. Введите реквизиты компании
3. Мы вышлем счет на email

Для Enterprise: свяжитесь с sales@taskmaster.pro
