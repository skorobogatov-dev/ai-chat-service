# Руководство по управлению задачами

## Создание задач

### Быстрое создание задачи
1. Нажмите кнопку "+" в правом нижнем углу или используйте сочетание клавиш `Ctrl+N` (Windows/Linux) или `Cmd+N` (macOS)
2. Введите название задачи
3. Нажмите Enter для создания

### Создание задачи с деталями
1. Откройте форму создания задачи
2. Заполните поля:
   - **Название** (обязательно): Краткое описание задачи
   - **Описание**: Детальная информация о задаче
   - **Проект**: Выберите проект из списка
   - **Приоритет**: Низкий / Средний / Высокий / Срочный
   - **Дедлайн**: Установите срок выполнения
   - **Исполнитель**: Назначьте ответственного
   - **Теги**: Добавьте теги для категоризации
3. Нажмите "Создать задачу"

### Создание повторяющихся задач
1. Создайте задачу как обычно
2. Включите опцию "Повторяющаяся задача"
3. Выберите частоту повторения:
   - Ежедневно
   - Еженедельно (выберите дни недели)
   - Ежемесячно (день месяца)
   - Ежегодно
4. Установите дату окончания повторений (опционально)

## Работа с подзадачами

### Создание подзадачи
1. Откройте карточку задачи
2. Найдите раздел "Подзадачи"
3. Нажмите "Добавить подзадачу"
4. Введите название подзадачи
5. Нажмите Enter или "Добавить"

### Преобразование подзадачи в отдельную задачу
1. Откройте подзадачу
2. Нажмите меню "⋮" в правом верхнем углу
3. Выберите "Преобразовать в задачу"
4. Подзадача станет самостоятельной задачей

### Перемещение подзадачи в другую задачу
1. Откройте подзадачу
2. Перетащите её на другую задачу с помощью drag-and-drop
3. Или используйте меню "⋮" → "Переместить в..." → выберите целевую задачу

## Установка приоритетов и дедлайнов

### Приоритеты
- **Низкий** (серый): Может быть выполнено в любое время
- **Средний** (зеленый): Стандартный приоритет для большинства задач
- **Высокий** (оранжевый): Требует внимания в ближайшее время
- **Срочный** (красный): Критически важная задача, требующая немедленного действия

### Установка дедлайна
1. Откройте задачу
2. Нажмите на поле "Дедлайн"
3. Выберите дату в календаре
4. Опционально установите время
5. Сохраните изменения

### Напоминания о дедлайнах
Система автоматически отправляет напоминания:
- За 1 день до дедлайна
- В день дедлайна (утром)
- При просрочке дедлайна

Настройте напоминания: Настройки → Уведомления → Напоминания о дедлайнах

## Назначение исполнителей

### Назначение задачи
1. Откройте задачу
2. Найдите поле "Исполнитель"
3. Начните вводить имя коллеги
4. Выберите нужного пользователя из списка
5. Исполнитель получит уведомление о назначении

### Назначение нескольких исполнителей (Premium)
1. В поле "Исполнители" добавьте нескольких пользователей
2. Каждый получит уведомление
3. Все исполнители смогут обновлять статус задачи

### Самоназначение задачи
- Нажмите "Назначить себе" в карточке задачи
- Или используйте кнопку "Взять в работу"

## Комментарии и вложения

### Добавление комментария
1. Откройте задачу
2. Прокрутите до раздела "Комментарии"
3. Введите ваш комментарий
4. Используйте @упоминания для уведомления коллег
5. Нажмите "Отправить" или `Ctrl+Enter`

### Форматирование комментариев
Поддерживается Markdown:
- **Жирный** текст: `**текст**`
- *Курсив*: `*текст*`
- `Код`: \`код\`
- Списки: `-` или `1.`
- Ссылки: `[текст](url)`

### Добавление вложений
1. Нажмите кнопку "📎 Прикрепить файл"
2. Выберите файлы с компьютера (до 25 МБ на файл)
3. Или перетащите файлы в окно задачи
4. Поддерживаемые форматы: изображения, документы, архивы, PDF

**Лимиты хранилища:**
- Basic: 1 ГБ всего
- Premium: 10 ГБ на пользователя
- Enterprise: 100+ ГБ

## Теги и категории

### Создание тега
1. Откройте задачу
2. Найдите поле "Теги"
3. Начните вводить название нового тега
4. Выберите "Создать новый тег: ..."
5. Выберите цвет для тега
6. Тег будет доступен для всех задач в проекте

### Использование тегов
- Добавляйте несколько тегов к одной задаче
- Используйте теги для фильтрации: нажмите на тег, чтобы увидеть все задачи с этим тегом
- Создайте систему тегов: например, #bug, #feature, #urgent, #needs-review

### Удаление тега
1. Настройки проекта → Теги
2. Найдите тег в списке
3. Нажмите "Удалить"
4. Тег будет удален со всех задач

## Фильтрация и поиск задач

### Быстрые фильтры
- **Мои задачи**: Задачи, назначенные вам
- **Команда**: Задачи всей команды
- **Просроченные**: Задачи с истекшим дедлайном
- **Без назначения**: Задачи без исполнителя
- **Завершенные**: Выполненные задачи

### Расширенный поиск
1. Нажмите на поле поиска (или `Ctrl+K`)
2. Введите ключевые слова
3. Используйте фильтры справа:
   - **Статус**: открытые, в работе, завершенные
   - **Приоритет**: низкий, средний, высокий, срочный
   - **Исполнитель**: фильтр по пользователю
   - **Дедлайн**: сегодня, эта неделя, этот месяц, просрочено
   - **Теги**: выберите один или несколько тегов
4. Примените фильтры

### Сохранение фильтров (Premium)
1. Настройте нужные фильтры
2. Нажмите "Сохранить фильтр"
3. Введите название (например, "Срочные багы")
4. Фильтр появится в боковом меню для быстрого доступа

### Операторы поиска
- `priority:high` - высокий приоритет
- `assigned:me` - назначено мне
- `due:today` - дедлайн сегодня
- `status:open` - открытые задачи
- `tag:bug` - с тегом "bug"
- `created:>2024-01-01` - созданные после даты

## Статусы задач

### Доступные статусы
- **Открыта** (To Do): Новая задача, ожидает выполнения
- **В работе** (In Progress): Задача в процессе выполнения
- **На проверке** (In Review): Требуется проверка перед закрытием
- **Завершена** (Done): Задача выполнена

### Изменение статуса
- Перетащите задачу между колонками на Kanban-доске
- Или откройте задачу и выберите новый статус в меню

### Кастомные статусы (Enterprise)
1. Настройки проекта → Статусы
2. Нажмите "Добавить статус"
3. Введите название и выберите цвет
4. Настройте workflow переходов между статусами

## Частые вопросы

**Q: Как создать подзадачу?**
A: Откройте задачу → раздел "Подзадачи" → "Добавить подзадачу"

**Q: Как установить повторяющуюся задачу?**
A: При создании задачи включите опцию "Повторяющаяся задача" и настройте частоту

**Q: Можно ли массово изменить статус задач?**
A: Да (Premium). Выделите несколько задач с помощью Ctrl+Click → меню "..." → "Изменить статус"

**Q: Как экспортировать задачи?**
A: Проект → меню "..." → Экспорт → выберите формат (CSV, Excel, JSON)

**Q: Почему не могу создать более 50 задач?**
A: В тарифе Basic ограничение 50 задач на проект. Обновите тариф до Premium для снятия лимита
