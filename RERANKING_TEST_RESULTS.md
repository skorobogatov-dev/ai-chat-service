## Технические детали работы

### БЕЗ Reranking
```
Запрос → Embedding (Ollama) → Поиск топ-3 по cosine similarity → Ответ
```

**Логи:**
- `Found 3 similar chunks (total candidates: 6)`
- Выбраны 3 чанка с наибольшим cosine similarity

### С Reranking
```
Запрос → Embedding (Ollama) → Поиск топ-6 кандидатов →
→ Reranking через Claude AI (2580ms) → Топ-3 наиболее релевантных → Ответ
```

**Логи:**
- `Found 6 similar chunks (total candidates: 6)`
- `Reranking enabled: reranking 6 candidates`
- `Successfully reranked 6 documents`
- `Reranking completed in 2580ms, selected top 3 chunks`

## Ключевые выводы

### ✅ Преимущества Reranking

1. **Лучшее качество контекста**
   - Reranking выбрал более релевантные чанки из большего пула кандидатов
   - Ответ содержит более точную информацию с конкретными датами и именами
   - Лучшая структурированность и хронологическая последовательность

2. **Семантическое понимание**
   - Claude AI оценил релевантность не только по векторному сходству, но и по смысловому содержанию
   - Запрос "про современную эпоху" получил ответ с конкретными историческими вехами

3. **Неожиданно быстрее!**
   - Несмотря на дополнительные 2580ms на reranking, **общее время ответа было меньше** (10179ms vs 10438ms)
   - Возможная причина: лучший контекст → более эффективная генерация ответа

### ⚠ Недостатки Reranking

1. **Дополнительный API вызов**
   - +2580ms на reranking (дополнительный запрос к Claude API)
   - +110 токенов (+3.1% стоимости)

2. **Сложность**
   - Более сложная логика обработки
   - Дополнительная точка отказа (fallback на embedding similarity при ошибке)

### 🎯 Рекомендации по использованию

**Используйте Reranking когда:**
- ✓ Важна максимальная точность ответов
- ✓ Сложные вопросы, требующие глубокого понимания контекста
- ✓ Есть большая база знаний с похожими документами
- ✓ Стоимость API не критична

**НЕ используйте Reranking когда:**
- ✗ Простые вопросы с очевидными ключевыми словами
- ✗ Критична скорость ответа (экономия 2.5 секунды)
- ✗ Ограниченный бюджет API
- ✗ Embedding similarity уже дает хорошие результаты
